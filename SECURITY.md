# Seguridad

La clave de la API vive en el teléfono. No la pegues en un issue, en un comentario ni en un commit. Si crees que una clave se ha filtrado, revócala en [console.x.ai](https://console.x.ai) y crea otra.

Un fallo que deje salir audio de la casa sin la frase clave, o que lea un mensaje sin que la persona diga que sí, es un problema de seguridad. Repórtalo en privado, en la pestaña Security de este repositorio (Advisories), no en un issue abierto. Di qué versión y qué teléfono, sin pegar la clave ni el texto del mensaje.

## Security

The API key stays on the phone. Do not paste it into an issue, a comment, or a commit. If you think a key has leaked, revoke it at [console.x.ai](https://console.x.ai) and make another.

A bug that lets house audio leave without the key phrase, or that reads a message before the person says yes, is a security problem. Report it in private, on the Security tab of this repository (Advisories), not in an open issue. Say the version and the phone. Do not paste the key or the message text.
